# `@b4moss/hermit-crumb`

Nuxt v4 向けテックドキュメントサイトの殻（module / 将来の CLI）。

初回公開は **v0.1.0**。実装詳細とスコープはリポジトリの [`docs/specs/`](../../docs/specs/README.md) を正とする。

## 開発（モノレポ）

```shell
# リポジトリルートで
npm install
npm run build -w @b4moss/hermit-crumb
```

## ステータス

Phase 0: パッケージ骨格のみ。module 本実装は Phase 2、CLI は Phase 4。
