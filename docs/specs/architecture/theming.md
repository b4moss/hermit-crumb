# テーマ（CSS 変数契約）

## 原則

見た目カスタムの **主契約は CSS 変数**とする。利用側は変数上書きを基本とし、コンポーネント実装のクラス構造や DOM 詳細への依存は推奨しない。

## パッケージの提供物

- デフォルトの CSS 変数定義（ライト／ダークを含む場合は `doc-site` の挙動に合わせる）
- 変数を参照するベーススタイル（module 経由で適用）

## 利用側のカスタム手段（優先順）

1. **CSS 変数の上書き**（推奨・主契約）
2. 生成された UI コンポーネントの直接編集（所有物として）
3. slots / 薄いラッパでの差し込み

## 非目標（初期）

- 生成 CSS ファイルの大改修を主経路にすること
- ユーティリティクラス体系の独自 DSL 化
- 実行時テーマエンジンの追加（`doc-site` に無いもの）

## semver との関係

| 変更 | 想定バージョン |
| --- | --- |
| 変数の追加（後方互換） | minor |
| 変数の削除・意味変更、デフォルト見た目／クラス構造の大きな変更 | major |
| トークン値の微調整（コントラスト修正等）で契約名が変わらない | patch または minor（影響範囲で判断） |
